# QKash

Cross-border remittance provider selection for East African corridors, comparing
QAOA against classical baselines on the same QUBO model.

This is a **research prototype**. It does not claim quantum advantage; its
experiments are designed to test for one rather than assume it.

Source: https://github.com/Q-solve/QS-FinTech-T1

## Note on data

This Space carries a copy of the audited RPW extract
(`data/processed/remittance_east_africa_clean.csv`, 4,026 rows) because the
application reads it at startup. The dataset remains untracked in the GitHub
repository by design. Keep this Space private unless that copy is cleared for
publication.
